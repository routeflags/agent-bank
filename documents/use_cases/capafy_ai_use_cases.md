# Capafy AI — ユースケース一覧

> **対象**: プロダクトマネージャー、開発チーム、経営者
> **作成日**: 2026-08-17
> **対象言語**: 日本語
> **バージョン**: 1.0

---

## 1. サービス概要

Capafy AI（ランプリー）は、AI ペルソナのマーケットプレイスです。
ユーザーは AI エージェント（ペルソナ）を購入し、チャットで利用できます。
出品者は自分の AI ペルソナを出品し、販売収入を得られます。

### 1-1. ステークホルダー

| ステークホルダー | 役割 |
|:---:|------|
| **ユーザー（購入者）** | AI ペルソナを閲覧・購入・チャット利用 |
| **出品者（販売者）** | AI ペルソナを出品・管理・収入獲得 |
| **プラットフォーム管理者** | 運営管理・決済管理・コミッション設定 |
| **AI プロバイダー** | OpenAI / Anthropic / Google による AI 処理 |

## 2. ユースケース一覧

### UC-01: 新規ユーザー登録

```
アクター: 未登録ユーザー
前提条件: ユーザーは未登録
主系列:
  1. ユーザーがトップページで「新規登録」を選択する
  2. メールアドレスとパスワードを入力する
  3. ユーザー名を入力する
  4. 利用規約に同意する
  5. 「登録する」ボタンをクリックする
  6. システムがアカウントを作成し、メール認証リンクを送信する
  7. ユーザーがメール認証を完了する
  8. システムがアカウントを有効化する
代替系列:
  5a. メールアドレスが既に登録済みの場合
    → エラーメッセージを表示し、ログインを促す
例外系列:
  - パスワードが弱い場合
    → パスワード要件を表示し、再入力を促す
```

### UC-02: ログイン

```
アクター: 登録済みユーザー
前提条件: ユーザーは登録済み
主系列:
  1. ユーザーが「ログイン」を選択する
  2. メールアドレスとパスワードを入力する
  3. 「ログイン」ボタンをクリックする
  4. システムが認証し、トップページにリダイレクトする
代替系列:
  2a. パスワードを忘れた場合
    → 「パスワードを忘れた」リンクからリセット手続き
例外系列:
  - ログイン試行が 5 回を超える場合
    → アカウントを一時ロックし、メールでロック解除手順を送信
```

### UC-03: AI ペルソナの閲覧・検索

```
アクター: ユーザー
前提条件: ログイン済み or 未ログイン均可
主系列:
  1. トップページのヒーロー検索にキーワードを入力する
  2. 検索ボタンをクリックする
  3. システムが一致するペルソナ一覧を表示する
  4. ユーザーがペルソナを選択し詳細を見る
代替系列:
  1a. カテゴリから絞り込む場合
    → 人気カテゴリ（生成AI、データ分析、開発等）を選択
  1b. 並び順を変更する場合
    → おすすめ / 新着 / 高評価 のタブを選択
```

### UC-04: AI ペルソナの出品

```
アクター: 出品者
前提条件: 出品者は登録済みでログインしている
主系列:
  1. 出品者が「出品する」を選択する
  2. ペルソナ名・説明・カテゴリを入力する
  3. 画像をアップロードする
  4. 価格（定額）を設定する
  5. AI モデル（GPT-4o、Claude 等）を選択する
  6. コミッション率を設定する
  7. 「出品する」ボタンをクリックする
  8. システムが出品を保存し、公開する
代替系列:
  7a. 必須項目が不足している場合
    → バリデーションエラーを表示し、修正を促す
例外系列:
  - 管理者による承認が必要な場合
    → ステータスを「承認待ち」とし、承認後に公開
```

### UC-05: AI ペルソナの購入

```
アクター: ユーザー（購入者）
前提条件: ユーザーは登録済みでログインしている
主系列:
  1. ユーザーが購入対象のペルソナ詳細を開く
  2. 「このスキルを利用する」ボタンをクリックする
  3. システムが Stripe Checkout Session を作成する
  4. ユーザーが決済情報を入力する
  5. 決済が完了する
  6. システムが UserPlanSubscription を自動作成する
  7. システムが Wallet に初回トークン（クレジット）を付与する
  8. ユーザーに「購入完了」メッセージを表示する
代替系列:
  5a. 決済が失敗した場合
    → エラーメッセージを表示し、決済画面に戻る
例外系列:
  - 既に購入済みの場合
    → 既存サブスクリプションを返し、チャット画面に遷移
```

### UC-06: AI チャット（トークン消費）

```
アクター: ユーザー（購入済み）
前提条件: ユーザーはペルソナを購入済みで、Wallet にトークンがある
主系列:
  1. ユーザーがチャット画面でメッセージを入力する
  2. システムが Wallet の残高を確認する
  3. システムが AI プロバイダー（OpenAI / Anthropic）にリクエストを送信する
  4. システムが AI レスポンスをストリーミングで受信する
  5. システムが UsageRecord を作成し、トークン使用量を記録する
  6. システムが Wallet からトークンを差し引く
  7. システムがレスポンスをフロントエンドに表示する
代替系列:
  2a. Wallet の残高が不足している場合
    → 「トークンが不足しています。追加購入してください」と表示
    → トップアップボタンを表示
例外系列:
  - AI プロバイダーがエラーを返した場合
    → エラーメッセージを表示し、トークンは差し引かない
```

### UC-07: トークン追加購入（ウォレットトップアップ）

```
アクター: ユーザー
前提条件: ユーザーは登録済みでログインしている
主系列:
  1. ユーザーがチャット画面の「追加する」ボタンをクリックする
  2. 現在の残高と追加オプション（¥1,000 / ¥3,000 / ¥5,000）を表示する
  3. ユーザーが追加する金額を選択する
  4. システムが Stripe Checkout Session を作成する
  5. ユーザーが決済情報を入力し、購入を完了する
  6. システムが Wallet にトークンを追加する
  7. システムが CreditTransaction（topup）を作成する
  8. 残高表示を更新する
代替系列:
  5a. 決済が失敗した場合
    → エラーメッセージを表示し、決済画面に戻る
```

### UC-08: 自動リチャージ

```
アクター: システム（AutoRechargeCheckJob）
前提条件: ユーザーが自動リチャージを有効にしている
主系列:
  1. AutoRechargeCheckJob が定期的に実行される
  2. システムが全ユーザーの Wallet を確認する
  3. 残高が閾値（threshold_cents）を下回るユーザーを特定する
  4. システムが Stripe で自動リチャージを実行する
  5. システムが Wallet にトークンを追加する
  6. システムが CreditTransaction（auto_recharge）を作成する
例外系列:
  - 月次上限（monthly_cap_cents）に達した場合
    → 自動リチャージをスキップし、ユーザーに通知
  - Stripe の決済が失敗した場合
    → エラーログを記録し、次回のジョブで再試行
```

### UC-09: 出品者収入管理

```
アクター: 出品者
前提条件: 出品者は出品済みで、販売実績がある
主系列:
  1. 出品者が「マイページ」で収入概要を確認する
  2. システムが以下の情報を表示する:
    - 総売上高
    - プラットフォームコミッション
    - 出品者コミッション
    - 直近の取引一覧
  3. 出品者が Stripe Connect で payouts を確認する
代替系列:
  2a. 販売実績がない場合
    → 「まだ販売実績がありません」と表示
```

### UC-10: 管理者によるコミッション設定

```
アクター: プラットフォーム管理者
前提条件: 管理者は管理画面にログイン済み
主系列:
  1. 管理者が「管理画面 → 決済設定 → Stripe」を開く
  2. プラットフォームコミッション率（%）を設定する
  3. 各出品ペルソナに出品者コミッション率（%）を設定する
  4. 「保存する」ボタンをクリックする
  5. システムが設定を保存し、以後の取引に反映する
```

### UC-11: ペルソナ詳細確認

```
アクター: ユーザー
前提条件: ユーザーはログイン済み
主系列:
  1. ユーザーがペルソナ詳細ページを開く
  2. システムが以下を表示する:
    - ペルソナ名・説明・画像
    - 価格（定額 / 無料）
    - AI モデル名
    - 出品者情報
    - 料金体系（トークン単価、概算利用料金）
    - 無料体験の有無と制限
    - プライバシー条件
    - 返金・キャンセル条件
    - 評価・レビュー（DB 実データのみ）
  3. ユーザーが「このスキルを利用する」ボタンをクリックする
```

### UC-12: チャット履歴確認

```
アクター: ユーザー
前提条件: ユーザーは購入済み
主系列:
  1. ユーザーが「マイページ」でチャット履歴を開く
  2. システムが過去のチャットセッション一覧を表示する
  3. ユーザーがセッションを選択する
  4. システムがメッセージ履歴を表示する
```

## 4. 決済モデル

### 4-1. 双方向コミッション体系

| モデル | 計算式 | 例 |
|--------|--------|-----|
| **Model A (AI Direct)** | トークン原価 × (1 + プラットフォーム%) | $0.00075 × 1.10 = $0.000825 |
| **Model B (Seller Persona)** | ペルソナ価格 × (1 + 出品者% + プラットフォーム%) | $15 × (1 + 0.20 + 0.10) = $19.50 |

### 4-2. ペルソナ価格プラン

| プラン | 価格 | トークン付与量 | 対象 |
|--------|------|:-----------:|------|
| 無料 | ¥0 | — | お試し用ペルソナ |
| ベーシック | ¥1,000 | 10,000 トークン | 個人利用向け |
| プロ | ¥3,000 | 50,000 トークン | ビジネス利用向け |
| エンタープライズ | ¥10,000 | 200,000 トークン | 大規模利用向け |

### 4-3. トークン単価

| AI モデル | 入力トークン単価 | 出力トークン単価 |
|----------|:------------:|:------------:|
| GPT-4o | $0.0025/1k | $0.01/1k |
| GPT-4o Mini | $0.00015/1k | $0.0006/1k |
| Claude Sonnet 4 | $0.003/1k | $0.015/1k |
| Claude 3.5 Haiku | $0.0008/1k | $0.004/1k |

## 7. リスクと制約

| リスク | 影響 | 対策 |
|--------|------|------|
| Stripe API キー未設定 | 決済が機能しない | 管理画面で設定 |
| AI プロバイダーアウトエージェント | チャットが利用不可 | エラーメッセージ表示、再試行 |
| トークン枯渇 | チャットが中断 | トップアップ誘導、自動リチャージ |
| 不正アクセス | アカウント乗っ取り | ログイン試行ロック、CSRF 対策 |
| 不正利用（過剰トークン消費） | コスト増大 | 月次上限、レート制限 |
