# BDD 計画書 — Issue #131・#133（ヘッダー右側の整備）

作成日: 2026-11-01 / ブランチ: fix/131-133-header（origin/main = cc76abb90 から分岐）
実装対象: `app/assets/stylesheets/views/_header.scss`, `app/assets/stylesheets/themes/_topbar.scss`,
`app/views/layouts/_global_header.haml` の3ファイルのみ。

## 調査による前提（設計根拠）

- 共通トップバーは `app/views/layouts/_global_header.haml`（`%header.topbar`）で、
  `application.haml:37` が `topbar_v1` フラグ無効時に描画する。`body` は常に `body.dark-theme`
  （`application.haml:7`）。
- `.header-inbox`（封筒アイコン）の DOM は `app/views/layouts/_header_right_visible_tablet.haml:2-3`
  のみが出力し、その partial を render しているのは `_global_header.haml:45` のみ
  （`grep -rn "header-inbox" app spec config` で2箇所）。
- レガシーの相対オフセットは `app/assets/stylesheets/views/_header.scss:169-174`
  `.header-inbox { position: relative; top: em(4); }`。`em(4)` は
  `mixins/type.scss:33` の `em()` = 4/16em = 0.25em。アイコンの font-size は
  `big-type`（`em(22)` = 1.375em）× 親 `.header-text-link` の 14px = **19.25px**
  → 0.25em × 19.25px = **4.8125px**（Issue #131 の DevTools 実測値と一致）。
- トップバー側は `app/assets/stylesheets/themes/_dark_header.scss:71-81`
  `.header-inbox-link { display: inline-flex; align-items: center; height: 100% }`
  が中央揃えを担う。よってアイコン中心 = バー中心（69/2 = 34.5px）に
  4.8125px が上乗せされて 39.3px ≒ 実測 38.5px になっていた。
- SCSS の読み込み順は `application.scss:19-23` = `require_tree ./partials` → `./views` →
  `./themes` → `./components`。`_topbar.scss` は `views/_header.scss` より後。
  ただし今回の境界は**特異性**で担保する（順序依存にしない）。
- `grep -rn "top-actions__logout" .`（node_modules/vendor/.git 除く）= markup 1件
  （`_global_header.haml:48`）+ SCSS 1件（`_topbar.scss:204`）のみ。
  `spec/e2e/navigation_spec.js` に logout 参照なし。
- Cucumber `features/support/feature_tests/section/topbar.rb:39-42` の `click_logout` は
  `.header-toggle-menu-user`（`_header_user_menu.haml:19-21`）内のリンクを押すため無影響。
- `t("layouts.logged_in.logout")` は `_header_user_menu.haml:21` と `_header_menu.haml:10` で
  引き続き使用 → locale のログアウトキーは削除対象にならない。

## タスク一覧（BDD）

### T1: #131 トップバーの封筒アイコンを縦中央に揃える（SCSS のみ）

- Given ダークテーマ・ログイン済み・1362px 幅（`--raku-topbar-h: 69px`）
  When `header.topbar a#inbox-link > i.header-inbox` を描画
  Then アイコンの中心 = 34.5px（バー中心と ±1px 以内）。
- Given 767px 以下（`--raku-topbar-h: 77px`）When 描画 Then 中心 = 38.5px。
- Given 未読あり When 描画 Then `.badge` は従来どおり `a#inbox-link`（`position: relative`）
  基準で配置され、位置・大きさが変わらない。
- Given レガシー文脈（`.topbar` 配下でない `.header-inbox`）When 描画
  Then `top: em(4)` が従来どおり効く（レガシー挙動を壊さない）。
- Given ガラス表現 When 比較 Then `background-color` / `backdrop-filter` / `box-shadow` は不変。

### T2: #133 ヘッダー右上の「ログアウト」ボタンを削除（markup + SCSS）

- Given デスクトップ・ログイン済み When ヘッダー表示
  Then `.top-actions` 内にログアウトボタンが無く、右側は
  「ユーザー名トグル → 受信箱 → マイページ →（言語切替）→（ハンバーガー）」の順。
- Given タブレット幅 When 表示 Then 同様に非表示（元から `visible-tablet` で 767px 以下は非表示）。
- Given どこからログアウトするか Then ユーザー名ドロップダウン
  （`_header_user_menu.haml:19-21`）とモバイルメニュー（`_header_menu.haml:8-10`）から可能。
- Given 未ログイン When 表示 Then ログイン / 新規登録ボタンの見た目は不変
  （`_topbar.scss:201-224` の共通ルールを維持）。
- Given マイページと受信箱 Then `.top-actions { gap: 10px }` の間隔・右端余白は不変
  （削除分 102px + gap 10px = 約 112px だけ右に詰まる）。
- Given CSS 出力 When `grep top-actions__logout` Then 0件。
