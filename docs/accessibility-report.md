## 背景画像上のテキスト（axe が自動判定できない領域）

axe-core は背景に**画像**があるテキストのコントラストを計算できず
`incomplete`（要手動確認）として扱う。違反 0 件でも、この領域は実際に
低コントラストの可能性があるため、Playwright + canvas による
**実ピクセルサンプリング**で追加検証した（2026/10/6 追加調査）。

### 検証方法

1. ページを deviceScaleFactor=2 でスクリーンショット
2. 各要素の実測 bounding box を canvas で切り出し
3. テキスト色（computed color）と背景ピクセルの相対輝度からコントラスト比を算出
   - チップ類はパディング領域（文字なし帯）、中央テキストは左右マージン列を標本化

### 適用した修正

1. **hero 背景オーバーレイ強化**（`_hero_section.scss`）
   - `rgba(13,13,13,0.55)/rgba(30,30,46,0.35)` → `rgba(10,10,12,0.78)/rgba(18,18,30,0.65)`
2. **hero 背景画像のグロー減光**（`raku/hero_bg.jpg` 再生成・ImageMagick）
   - グロー透明度を大幅に下げ、テキスト領域の輝度バリアンスを縮小
3. **タグチップ**：透過白 5% → 暗チップ `rgba(12,12,18,0.72)` + 文字 `#d4d4d4`
4. **バッジ**：`#c41e3a` → `#ff6b6b`（暗地 6.2:1）、地色 `rgba(25,8,12,0.9)`
5. **サブタイトル**：`#999999` → `#c9c9c9`
6. **ヘッダー**：`.header-wrapper` のレガシー白背景を dark テーマで透明化
   （`.header` の `--bg-secondary` #1e1e1e を透かす）。匿名ログインリンクは 5.85:1 に
7. **出品カバー画像オーバーレイ**（`mixins/_layout.scss`）
   - `rgba(0,0,0,0.6)` → `rgba(0,0,0,0.82)`（白画像上の白/teal テキスト確保）
